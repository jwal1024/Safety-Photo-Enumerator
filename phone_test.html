Test the photo survey on your phone

Allow 15–25 minutes. Use the actual phone and browser intended for the work. Open in Chrome on Android or Safari on iPhone, in a regular tab rather than an email/messaging preview.

Reviewer A · Reviewer B. Use the reviewer code your coordinator supplied. Keep to practice locations 1 and 2. Use a session beginning PHONE_TEST_, followed by reviewer/date, and write PHONE TEST ONLY — exclude from analysis in the note. Do not test over existing real work.

  1. Open on Wi-Fi. Enter your code and test session; refresh once online. Check portrait and landscape. There should be no sideways scrolling or cut-off controls.
  2. Inspect all three photos. Open each full-size photo and close it. Try zooming and rotating. Check that details are large enough to rate and that you can return to the questions.
  3. Complete practice location 1. First try saving with missing answers: the app should explain what is needed. Record safety, light conditions and confidence; confirm all views were inspected. Save safety, then complete the features, photo usability and recognition. Initial safety stays preserved; nighttime illumination is not applicable for daylight photos. Include the test note.
  4. Send online. Tap Send saved answers. The confirmed-received count should rise and awaiting-submission return to zero. Tap again without editing; this should add no new Sheet row.
  5. Save and reopen. Tap Save JSON and find the file in Files/Downloads. Close the tab and reopen the same link/browser. Check progress survives. Resume JSON should accept the backup and keep newer work.
  6. Prepare an offline batch. Return to practice location 1 using the Location selector. Open Offline tools, choose Save current + next 9 locations offline and wait for Photos saved. Check next 10 photo cache should show 30/30 views and page controlled for offline use. Reload online if prompted.
  7. Test airplane mode. Disable Wi-Fi as well as mobile data. Refresh/reopen, visit practice location 2, view all photos and complete it offline. Sending now should leave it saved and awaiting submission.
  8. Reconnect and send. Restore internet, send answers, and check confirmation/zero awaiting submission. Save another JSON backup.

Send your coordinator: phone model, OS/browser versions, reviewer A/B, pass/fail for each step, download/loading time, time per practice location, and screenshots/exact error messages. The coordinator should match test sessions in the private Sheet's PhotoRatings tab and exclude test records from research analysis.

Pause before real coding if images are missing, answers disappear, JSON cannot be saved, online submission never confirms, or offline preparation fails when offline work is required. Use a new session/date for real work; keep the assigned reviewer code. Save/send at each break. Core ends at 84; extension is optional.
